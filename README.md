# Movements

A small, browser-only image movement studio.

## Try it

Open `index.html` in a browser. Press **Use sample** to try the included image,
or use **Upload an image** or drop an image onto the preview. Adjust the
movement slider, then press **Let’s go!** to play or pause the preview. Images
stay local to your browser.

The interface uses Material 3-inspired color roles, slider, dialog, and button
patterns:

- [Dialogs](https://m3.material.io/components/dialogs/overview)
- [Sliders](https://m3.material.io/components/sliders/overview)
- [Buttons](https://m3.material.io/components/buttons/overview)
